# 医疗设备故障排查通用指南

## 一、故障排查方法论

### 1.1 排查五步法
1. 观察：记录故障现象、故障码、发生频率、环境条件
2. 隔离：确定故障范围（机械/电气/软件/操作）
3. 验证：通过测试确认假设，逐一排除可能性
4. 修复：按操作规程执行维修
5. 验证与记录：测试修复效果，记录维修过程和结果

### 1.2 安全原则
- 维修前必须断电并执行LOTO（上锁挂牌）
- 高危操作（电机复位、高压测试）必须两人在场
- 维修完成后必须进行功能验证
- 所有维修记录必须保存3年以上

## 二、手术床常见故障

### 2.1 背板不动作
可能原因：电机故障、驱动板故障、机械卡死、限位开关触发、CAN通信中断
排查顺序：
1. 检查故障码
2. 听电机是否有启动声音
3. 手动盘车检查机械阻力
4. 万用表检测电机绕组
5. 检查控制信号是否到达驱动板

### 2.2 床体自动下降
可能原因：液压电磁阀泄漏、液压缸密封失效、控制阀卡滞
排查顺序：
1. 标记初始高度位置
2. 断电后观察是否继续下降
3. 检查液压管路是否有油迹
4. 拆检电磁阀

### 2.3 倾斜功能失效
可能原因：倾斜电机故障、限位开关触发或损坏、传动齿轮损坏
排查顺序：
1. 检查倾斜限位开关状态
2. 手动低速操作倾斜，听电机是否运转
3. 检查传动齿轮啮合状态
4. 检测电机电流

## 三、C臂常见故障

### 3.1 图像质量差
可能原因：准直器位置异常、探测器校准失效、X射线参数不当、线缆干扰
排查步骤：
1. 执行暗场和增益校正
2. 检查准直器叶片位置
3. 调整曝光参数（kV/mA）
4. 检查信号线缆屏蔽

### 3.2 C臂无法曝光
可能原因：管球过热保护、安全联锁触发、脚踏开关故障、高压发生器故障
排查步骤：
1. 检查是否有E4003报警
2. 确认所有安全联锁正常
3. 测试脚踏开关FSW-CA-001
4. 联系厂家检查高压发生器

### 3.3 C臂运动异常
可能原因：伺服参数偏移、编码器故障、机械卡滞、电机驱动故障
排查步骤：
1. 执行编码器归零校准
2. 检查各轴导轨润滑
3. 恢复伺服驱动器出厂参数
4. 手动盘车检查机械阻力

## 四、日常维护检查表

### 4.1 手术床日检
- [ ] 通电自检无错误码
- [ ] 各关节运动平稳无异常
- [ ] 急停按钮功能正常
- [ ] 手控器所有按键正常
- [ ] 外观无损伤变形

### 4.2 手术床月检
- [ ] 导轨润滑检查（5处：背板、腿板×2、升降、倾斜）
- [ ] 电气接线紧固
- [ ] 限位开关功能测试
- [ ] 液压系统油位检查
- [ ] 电机电流基线记录

### 4.3 C臂日检
- [ ] 开机自检完成
- [ ] 各轴运动正常
- [ ] 图像质量测试
- [ ] 急停功能测试
- [ ] 脚踏开关功能测试

### 4.4 C臂月检
- [ ] 编码器精度验证
- [ ] 导轨润滑（旋转、升降、前后平移）
- [ ] 散热风道清洁
- [ ] 线缆外观检查
- [ ] 准直器功能验证
